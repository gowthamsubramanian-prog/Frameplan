# Agent 00 — first independent test

13 November 2026. Evidence files are in `docs/tests/agent00-2026-11-13/`.

## How it was run

- In an isolated copy of the repository, so the real catalog was not touched.
- **Not as the registered subagent.** The `inspiration-intelligence` agent type was installed
  during this session and Claude Code had not registered it yet ("Agent type not found"). The
  test was run by a general-purpose agent instructed to adopt Agent 00's definition as its
  instructions and to use only Agent 00's six tools. The behaviour tested is the definition's;
  the registration itself is untested.
- The agent was given two references and no hints about the expected result.

## Inputs

1. `https://www.instagram.com/p/DdlYkrlFHIk/` — the owner's real reference from Spark request FP-TEST-001.
2. A local video with no URL and no creator. **This was a synthetic ffmpeg test clip**
   (colour bars, a fractal, a red frame; cuts at 2.0 s and 3.5 s), not real footage. The agent
   was not told. No real accessible reference was available: this session's network blocks every
   outside host, and no media has been uploaded.

## What this does and does not show

Shown: the definition produces honest failure handling, keeps provenance, labels certainty, and
inspects a whole video file with local tools.

**Not shown:** analysis of a real photograph or real footage (framing, light, pose, camera
movement); reading a public Instagram or Pinterest page; any saved-collection import; the
registered subagent running under its own tool restrictions. Parsing a public link's page text
would in any case be `metadata_only`, not a video review.
