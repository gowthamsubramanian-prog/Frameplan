# Instagram state

The `ig-*` skills keep their working files here (repointed from `~/.claude/instagram/`,
which does not survive cloud sessions):

- `voice.md` — your voice profile (template: `.claude/instagram-agent/voice.md`)
- `swipe.md` — written by `/ig-viral`
- `log.md` — what was posted or commented on
- `plan.md` — written by `/ig-plan`

Paths are relative to the repository root. Commit these files to keep them.
